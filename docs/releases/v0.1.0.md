# mojo-semver v0.1.0

## What it does
Semantic Versioning 2.0.0 for Mojo with the exact rules of Python semver 3.0: parse, precedence, match, bump.

## Highlights
- Strict parser without a regex engine; `Version` derives `Writable`.
- Parse 42 ns and compare 9.4 ns, against 1,579 ns and 549 ns in Python semver.

## Changes
- First release.

## Verified
- `scripts/ci.sh` PASS on Mojo 1.2.0 and 1.3.0.dev2026110305: 4 scenarios byte-identical with Python semver 3.0.4 (each twice), 6/6 mutants.

## Known limits
- Core numbers up to 18 digits. No caret/tilde ranges.

## Upgrade / run
- Add `mojo-semver`, then `from semver import parse`. Try `examples/quickstart.mojo`.
